# 白身 · Ancient China NPC Game

一個以**小人物**為中心的漢末開放世界原型。你不是諸侯，是河谷邊某個縣裡的一個白身：
先替人跑腿掙口飯，攢下人情把村裡的人一個一個帶走，再帶著這幾個人去摸山賊的窩。

不是策略遊戲換皮 —— 狀態樹的頂端是**一個人**，不是一個勢力。
你不會有「全國糧倉」這種欄位，你只有「你身上有多少錢、你認識誰、你欠誰人情」。

```
npm install
npm run dev      # http://localhost:5173
npm test         # 戰鬥手感的模擬(vitest)
npm run build
```

WASD 走、Shift 跑、**E 搭話**、**F 用場所**、空白鍵揮刀、J 日誌。

## 現在能玩到什麼

- **世界**：程序化河谷 —— 高度場、河、聚落、農田、道路、四季植被、晝夜與天氣。
  一切隨時間變的東西都從單一 `skyFor(hour, season, weather)` 導出，
  各算各的下場是黃昏的太陽配上正午的霧。
  樹是逐棵配色的（秋林金鏽赭綠雜在一起），地表有斑塊與顆粒；
  春有花樹花瓣、夏有螢火蜻蜓、秋飄落葉、冬積薄雪 —— 季節不是換個色調，是**發生**的。
  樹隨風搖，村裡有雞犬飛鳥，河上有魚躍泊船，酒肆挑旗，清晨河谷起霧；
  夜裡月亮按曆法圓缺（十五望），星野銀河跟著晴夜出來，河面是真反射，
  亂兵夜行打火把。村民衣色分行當、老人白髮弓背，搭話有側臉剪影立繪。
- **日子**：十日一旬，三旬一月，四季一年。時間會拿走東西 ——
  每天要吃糧、每旬要交租、每年秋後稅吏上門。
  在有曆法之前，「今天第幾天」算出來永遠是 0，村子從開局起就沒動過。
- **生計**：糴米糶米、下田扛包砍柴、賃屋置屋、睡一覺到天亮。
  每個動作都寫明花幾個時辰 —— 這個遊戲真正稀缺的是時間，不是錢。
- **人**：三十八個有名有姓的村民，各有行當、脾氣、年紀、**籍貫與親眷**。
  他們會老、會病、會歿；你做的事會沿著血緣傳出去。
  跟著你的人有心思，要走之前一定先抱怨。
- **兩套名聲**：官府記的「功績」和鄉里傳的「鄉望」是兩回事。
  剿賊記功；扶老賑饑官府一個字不寫，可是全村都知道 —— 而招人看的是後者。
- **差事**：活從人嘴裡給，不從選單刷。剿匪、搶收、護院、尋人都要**自己走出去辦**：
  剿匪指的是地圖上真的那一夥；搶收是你在田裡做的那幾趟工；
  護院是天亮時你人在不在村裡；尋人是那個人真的蹲在田埂上，找到還得把他帶回去。
- **打架**：不切場景，架就在你站的這塊地上打。沒有血條，傷勢用姿態講。
  士氣歸零就轉身跑。打贏可以招安 —— 收下來的人要吃你的糧。
  大夥的寨子有**弓手** —— 隔十來步放箭、你逼近他就退。箭有飛行時間，
  側著跑就躲得開：站著不動本身就是挨箭的姿勢。
  放倒最後一個的那一秒，慢鏡拉長、鏡頭壓低推近 —— 收場面板等這一拍演完才出。
- **賊會下山**：治安差、秋收前後，他們成夥往村子走。你攔得住就攔，
  攔不住村子就挨這一下。天黑以後他們老遠就看得見你。
- **天災**：旱、澇、蝗、疫。災年散糧賑濟換不到一個銅錢，
  換到的是全村都知道你在最難的時候拿出了東西。
- **出身**：五種來歷 —— 佃農之子、破落士族、行商之後、逃卒、游俠兒。
  它們不給你技能，給的是一副底子、一點家當，以及村裡人一開始怎麼看你。
- **聲音**：腳步、刀風、蟲鳴、雨，全部現算，不帶一個音檔。
  古琴也是 —— Karplus-Strong 撥弦，五聲音階現編的散句，幾十秒一段，
  打起來就停。沒有「曲子」，聽起來像有人在遠處隨手撫弦。
- **縣城**：半天路外的另一個地方 —— 城牆、市集（米貴一成半、鐵器只有這裡有）、
  客棧、縣衙（投書自薦看鄉望；賊坐大了會貼榜懸賞）。八個有名有姓的城裡人各在其位。
- **兵器**：拳腳、木棍、環首刀、長矛、獵弓。手上就一件，改的只有夠得著多遠、砍下去多重。
  一寸長一寸強做在命中上 —— 拿短傢伙的人得先擠進來才打得到。
  獵弓是唯一改**打法**的一件：空白鍵放箭，朝你面對的方向飛，
  搭箭上弦比揮刀慢，貼了身只剩一根軟棍 —— 別讓他們貼上來。
- **切磋**：點到為止的打，和真打共用整套戰鬥。贏了漲鄉望，輸了拍拍土站起來。
- **叫陣**：站到寨外喊一嗓子。兇的頭子好面子，多半提刀出來單挑（面子是他坐那把
  交椅的本錢）—— 贏了他，全夥樹倒猢猻散；不肯出來就是罵一句一擁而上。
  **越肯出來的越難打**：兇窩的頭子七成三應戰而你只有四成三贏面，
  毛賊首九成三贏面卻只有四成四肯露臉。夜裡不給喊 —— 摸黑靠近的價值就是他們沒醒。
- **亂兵過境**：第一個不能用刀解決的威脅。酒肆花五個錢買到「還有兩天」，
  人不在就全身而退 —— 提前得信的全部價值就是「走」。
- **流民**：世道爛出來的人。收留（不要身價錢的人手）、施粥（換鄉望）、或不理。
- **仇家**：從你手裡跑掉的那幾個記住了你的臉。攢夠人（三個以上）過些日子，
  他們會**衝著你**來 —— 不是搶村子，是找你，半夜摸下山。
  動手前一定先有風聲：酒肆裡有人打聽你住哪。打回去這筆帳就結了。
  於是「打得多乾淨」第一次有了長期的後果：招安的成了自己人，倒下的不會回來，
  <b>跑掉的會回來</b>。
- **採藥治傷**：藥長在山坡上，不長在市集裡 —— 而山坡正是賊走的路。
  一趟採三五株（**認得藥的人才採得到**，見識管用；冬天上山是白跑），
  採空的那一叢十二天才長回來。自己敷兩株、送病家三株 ——
  一趟採的**不夠兩個人用**，於是每次下山都是同一個問題：這副藥給自己的腿，
  還是給河邊那個老船工。藥讓傷**好一倍快**（一旬敷一次），不是立刻好；
  **敷過藥的破相不留疤** —— 疤是「那次沒藥可敷」的紀念。
  村裡病倒的人門口挑一條白布，走過去能探病、送藥（一副藥把七十歲的死路
  從一成五砍到二分，但不是免死金牌）。縣城有藥鋪：買藥、賣藥、
  出得起八十錢就請郎中一次治利索。
- **義結金蘭**：全遊戲唯一一條**不由錢維持**的關係。別的人都是雇來的 ——
  吃你的糧、按旬領月錢、你名聲爛了他就走；義兄弟**不領月錢，也不會走**
  （斷糧兩頓不散，鄉望墊底也還在）。最多兩個，桃園那一回也只有三個人。
  門檻：得先跟過你（沒一起走過路的人談不上生死）、交情夠、擺得起一桌酒。
  **結了就退不掉** —— 他佔著你的人頭上限一輩子。
  代價與意義都在同一件事上：**你要倒下的那一下，他橫過來擋在前頭，然後他倒下。**
  一場只擋一次，擋過的人一定沒回來；落幕那一頁上，他們自己有一行。
- **落幕**：六種收場（餓殍、病歿、陣歿、安身、出谷、名動一鄉），沒有一種叫「通關」。
  傷還沒好又被打倒,就是死 —— 帶傷出門是在賭命(帶傷能走,慢、跑不動)。
  **傷有形狀**:腿傷瘸一個月、臂傷砍下去是輕的、破相好了也留疤 ——
  疤跟你一輩子,記在生平裡。
  生平那一頁列的是名字，不是分數。好結局可以推掉——旁邊擺著「再撐一年」。
- **尋路**：河對岸走得到（會為了橋繞遠路），到不了的地方會停下來。

## 幾條踩出來的規矩

**世界與畫面**

- 顏色烘進 `color` attribute + 材質開 `vertexColors`，一個 InstancedMesh 才能有多種顏色 ——
  這一步讓動畫與批次不再互斥。
- 高度函式必須是純函式，並且網格頂點與物件放置**共用同一份**，
  否則房子會浮空或陷進山裡。
- 障礙要分「擋人」和「擋鏡頭」兩種形狀：樹幹擋人不擋鏡頭，樹冠反過來，
  敞開的堂屋擋鏡頭卻不能擋人（不然村民會被自家卡死）。
- 圓形障礙要走切線。一步只有幾公分，貼上樹幹以後兩個軸都還在圓裡，
  人就永遠黏在那棵樹上；一叢樹圍成的凹角連切線也過不去，所以自動尋路要能往兩邊偏著試。
- 鏡頭求解是三段：**先繞、再抬、最後才收近**。人站在樹冠底下時抬高沒有用。
  退無可退時要退到「擋得最少」的那個位置，而不是梯級的最後一階 ——
  貼著後腦勺是所有壞位置裡最壞的一個。
- 擋在鏡頭與主角之間的樹自己讓開。按「離鏡頭多近」篩兩頭不討好：
  調小了中間那棵照樣糊住你，調大了走在林子裡整片林子跟著融化。
  該問的是**擋不擋著你** —— 判斷是一根鏡頭指向主角的圓柱。
- 會走路的東西一律問 `groundAt()` 而不是 `terrainHeight()`，否則橋只是擺著看的。
- 盯 draw call，不是三角形數。三角形再多，一次畫完就不痛。
- `instanceColor` 是**乘**在 `material.color` 上的 —— 用它的材質底色必須是白，
  不然基色乘基色，整片林子黑一倍。
- 大面積的半透明抖動篩子不能用 Bayer 棋盤格（滿屏網紋），要用位置雜湊的噪點，
  而且羽化帶要窄：帶一寬，貼著鏡頭的整棵樹冠都落在「半透」裡。
- 鏡頭的地形檢查要**沿視線取樣**，不能只查落點 —— 營地貼著山根時，
  鏡頭退到山脊另一側落點是乾淨的，可整座山正好橫在中間。
- 想在 bloom 裡發光的東西，顏色要推到 HDR（>1）：`toneMapped=false` 只繞過
  材質層，合成器裡那道全屏 ToneMapping 躲不掉，≤1 的「亮色」出來就是灰點。
- 截圖會凍住 rAF —— 截圖裡的 FPS 表讀數是假的，量幀率要另開不截圖的穩態採樣。
- 天穹著色器的 `sunPosition` 和平行光的位置是**兩件事**：夜裡把月亮餵給天穹，
  半夜的天會亮成白晝。拆成 `sun`（天）與 `light`（照明）兩個欄位。
- 夜間光源從「地平線下」挪到頭頂後，強度要跟著砍 —— 光真的落在地上以後，
  同樣的數值夜就成了暖洋洋的黃昏。
- 會受光的東西用 standard 材質 —— 白色 basic 一過 bloom 閾值就是畫面上的閃點
  （蝴蝶翅膀、河岸一排莫名的光斑，都是這麼來的）。
- 位置清單和幾何要在**同一個迴圈**裡出：分兩處各自做越界檢查，
  漏掉一處就是 `undefined.door` 把整棵 React 樹炸下來，而畫面上只是一片霧。
- 「門前一步」「攤位偏移」這類**往外算**的落腳點會算到河裡去。房子與碼頭本身都避開了水，
  偏移沒有 —— 碼頭工人泡在河裡幹活、病家的白布竿插在水面上，是同一個根因。
  一律過 `dryLandNear()`。
- 散點鋪一叢要用 `sqrt(rand())` 當半徑：直接乘 `rand()` 的話點全擠在外圈，中間反而是空的。
- 世界上的東西**遠遠認不出來就等於不存在**。第一版藥草十五根稈、花頭 0.055，
  走到跟前才看得見四五個白點 —— 十二叢藥草等於十二個看不見的按鈕。
  而**認錯了比認不出來更糟**：0.13 的近白花瓣讀作螢幕壞點，
  沒貼圖的 `pointsMaterial` 雪片是一堆白方塊。
- three 的 `getHSL` 預設讀**工作色彩空間**（線性），`setHSL` 預設寫 **sRGB**。
  來回一趟剛好抵消，所以看不出來；露餡的是在中間**改一改**：
  針葉樹 `#2c402a` 在 sRGB 裡明度 0.208、在線性裡只有 0.037，
  上下各抖 0.09 的話一半落到 0 以下 —— 2600 棵有 644 棵是純黑的。
  凡是 `getHSL → 改 → setHSL`，兩頭都要指明同一個空間。
- **有些畫面 bug 眼睛分不出來**。黑樹散在暗綠的林子裡只像「那邊背光」；
  要把 `instanceColor` 撈出來數，才知道是四分之一。純邏輯那一半抽進 `palette.ts`
  用測試釘（`palette.test.ts`），`tools/probes/scenery.mjs` 再掃一次執行期。
- `vertexColors` 和 `instanceColor` 是**兩件不同的事**。開了 `vertexColors`
  而幾何沒有 `color` 屬性，著色器照樣去乘那個屬性（WebGL 給的是 `(0,0,0)`），
  整批東西就是純黑的 —— 而且怎麼調光都沒用，因為根本不是光的問題。
  顏色烘在頂點裡（人的身體）才開它；顏色是每個實例一份（草、樹）就別開。
- 葉片卡的法線要**造假朝上**，不能用 `computeVertexNormals`：真法線垂直葉面，
  背光那面整片黑。而且別靠 `side: DoubleSide` —— 背面 three 會把法線翻過來，
  翻完朝下又是黑的，得自己補反繞序的三角形。
- 地形網格一格 1.73 公尺，而擺放讀的是解析高度函式，兩者在起伏處差得出十幾二十公分。
  樹和房子夠高看不出來，**一叢三十公分的草會整叢埋進坡裡** ——
  矮東西要把根紮到地面以下，再整個抬高一點。
- 遮擋讓路要比**張角**不是比公尺。半徑固定的圓柱「離鏡頭越近佔的畫面越大」，
  一棵樹冠貼上鏡頭就糊掉半個屏幕；比張角的話，挖掉的洞在畫面上永遠只有主角那麼大。
- 貼在曲面上的東西，**「凸出多少」要是一個看得懂的數字**，不是兩個座標湊出來的結果。
  眼球第一版凸出臉面 0.12R —— 正面完全看不出來，四分之三角度是兩隻黏上去的護目鏡。
- **又長又貼面的東西要切成幾段**，每段自己算深度。一整條直板貼在圓臉上只有正中間貼得住，
  眉尾會翹起來浮在空中；而切了段以後，**段與段要疊夠**（12% 不夠，45% 才連得起來），
  否則順著曲面彎過去、每段的 z 各不相同，斜著看就讀成一條虛線。
- 兩張要貼在一起的曲面，**用同一條輪廓線放大**，別另拿一顆球去蓋。
  球和顱骨形狀不同、段數也不同，兩張面互相穿插 —— 髮線是一條鋸齒爛邊。
- 鑲邊（衣領、袖口）要**對比色**，不是把底色壓暗。深藍袍上的深藍領正面等於不存在；
  素色的麻緣配什麼袍子都成立，而且離多遠都讀得出來。
- 一個世界只有四種頭，那不是一個村子，是一批複製人。
  變體要多（露髻／裹幘／笠／鬍），而**身量**是最便宜的一味：矩陣裡本來就有縮放這一欄。
- 看美術要湊到臉前面，可鏡頭解算器每幀往肩後拉，湊得越近推得越狠 ——
  用 `__freezeCam()` 凍住它，否則一公尺的機位擺完二十六毫秒就沒了。
- 角色的「絕對高度常數」（袖口、腰帶、頭的落點）是兵器掛點的地基，
  改側影時**只動下擺不動它們** —— 動了要同時改七個檔案，而且改錯了刀會長在肚子上。
- 一個世界共用的身體改了側影，**每一個掛這副身體的地方都要跟著改**。
  下擺提高而某處沒加腿，那處的人就成了半截 —— `tools/probes/figures.mjs`
  一種身子拍一張，就是為了讓「漏了誰」一眼看得出來。
- 截圖腳本擺完鏡頭要**立刻按快門**：解算器每幀把鏡頭往主角肩後拉，半秒就收回去了。
  取景點也別在村子裡隨手挑，十次有八次埋在屋簷或樹冠裡 —— 河邊最保險，
  水面上不長樹也不蓋房。
- `camera.position` 進了一個 `NaN`，**從那一幀起整個畫面永遠是黑的，而且不報錯**
  （NaN 過 `lerp` 還是 NaN）。`__probe().player` 是 `[x, z]` 兩個數，
  當成三維座標用就會這樣。

**規則與數值**

- 戰鬥手感只能空跑一千場調，不能看畫面調 —— 見 `src/game/combat.balance.test.ts`。
- **整套經濟也要空跑**（`economy.sim.test.ts`）。每個數字單獨看都合理，
  合起來是不是一條活得下去的曲線，是另一個問題 ——
  第一次跑出來是「一年攢下一萬三千錢，而一間屋子六百二」：
  一天的工能買一個月的糧，「過冬」這個主題根本不存在。
  現在的規矩是**一天的工換三四天的口糧**，於是打工養不起隊伍，只有差事養得起。
- 糧價佔收入的比重，才是「荒年」有沒有份量的關鍵。佔一成七的時候，
  米價翻倍只削掉三成盈餘；佔三成五的時候，削掉六成。
- **網格比最窄的通道還粗的時候，那條通道會安靜地消失。**
  橋板三步寬，導航格四步一格 —— 整座橋可能落在兩個取樣點中間。
- **只被測試用到的匯出不是死碼，是被釘住的規格。**掃「零呼叫」的時候別排除 test 檔。
- 卡住的修法，先問「真人遇到這種情況會怎樣」。戰鬥僵局不必枚舉每種卡法：
  真人會走開，所以久沒人挨刀就讓士氣垮掉，這場架自己散。
- 差事卡上寫「需人 5」，帶了 5 個就得真的打得贏。這個數字是空跑出來的（`menNeeded`），
  而且測試**直接引用同一個函式**：各抄一份，兩邊遲早漂移。
  （早先寫成 `count - 1 + fierce`，到五個兇賊就成了謊：它說帶 6 個，實際勝率 16%。）
- 「他是主角」和「他由外面推」是兩件事。合成一個 `isPlayer`，
  空跑的場子裡主角就成了一尊不動也不揮刀的木頭 —— 量出的 4% 勝率量的是測試少了一個人。
- **「誰比誰高」全部成立，數字仍然可以錯二十倍。** 病死率第一版每條比較都過，
  而七十歲的人每天有一成六的機會病倒。要另外立一條真正的規格：空跑一年，死不到五個。
- **驗權重不能靠「把門檻壓到極低看回傳哪一種」** —— 那量到的是迴圈順序。要真的擲四千次去數。
- 一個函式的註解說它「每旬推一次」，就別每天叫它。村況的數字是按旬寫的，
  照天推是六天把一村的收成歸零 —— 世界不是變嚴酷，是時間單位錯了十倍。
- **一個「救你一命」的機制,要空跑才知道它救不救得了你。** 義兄弟擋刀第一版把主角
  撈回一成八的血 —— 空跑八十場,倒地率<b>一個點都沒動</b>:下一刀照樣要你的命,
  它只是把死推遲兩秒。同一次空跑還抓出一個更深的錯:那一刀原本走 `shakeMorale`,
  而那個函式算的是「我方少了一個人」(我方 −15、對面 +5)——
  於是**他替你死的那一刻反而幫了對面一把**。可是場上兩邊看見的根本不是同一件事:
  你這邊是死戰,對面是「這夥人是肯替人死的」。改成兩邊同向擺動以後,它才真的救得了人。
- **「應該更慘」的直覺常常是錯的，空跑會告訴你。** 送藥這條線的測試按感覺寫成
  「生路從三成拉到七成」，一跑才知道七十歲的人不吃藥本來就有八成五活得下來 ——
  病死在這個世界一向不是常態。藥真正做的事是**把病程的尾巴剪掉**
  （四天→不到兩天），而 `deathChance` 隨病程往上爬，尾巴一剪死亡率就掉一個數量級。
  不要為了讓新系統顯得重要，回頭把舊系統調狠。
- 新兵種要和它**頂替的東西**配平，不是憑感覺給數值：弓手替換隊尾的刀手，
  第一版箭太軟，空跑出來「有弓的寨比沒弓的好打十五個點」——
  對照組（`archers: 0`）一跑就現形。
- AI 拿了新兵器要**會用它**：「站定才射」的弓手空跑五十場 3 勝，
  和拳腳一個水準 —— 被追的整段路上一箭不放。射擊要優先於走位，
  放箭那半秒站住腳，被追近一步半就是弓的代價，不必另外扣什麼。
- **人數優勢會飽和**（圍毆有上限），帶到第九第十個人添的全是炮灰：
  七個兇賊的窩帶十個人照樣一成幾勝率。所以承諾的邊界也是規格 ——
  需人超過八個的窩不開剿匪的活，那樣的窩走懸賞和夜襲。

**介面與世界的接縫**

- 同一個位置上兩件事都成立時，**不該由程式替玩家猜哪一件**。
  E 兼管「搭話」和「進場所」的下場是市集和碼頭永遠進不去 —— 那兩處整天站著人。
- 場所要掛在世界既有的錨點上（房子的門前一步是現成的），不能憑座標點一個地方，
  不然玩家走過去會卡在別人家的牆裡。
- 世界可以對你不利，但**不能瞞著你**。糧見底、租到期、有人走了，
  都要在日誌上留一句話，否則玩家會覺得遊戲在偷偷扣他的東西。
- 打聽來的情報必須是真的，從世界的實際狀態讀。**假情報比沒有情報更糟** —— 玩家會學會不聽。
- 要走之前一定先抱怨。沒有預兆的離開像是系統在耍人；抱怨過一次再走，那是他自己的決定。
- 同名的函式擺在不同檔案裡是顆定時炸彈:`company.homeOf` 回籍貫(字串)、
  `places.houseOf` 回住處(物件)。第一版兩個都叫 homeOf —— 這次是型別擋下來的,
  下次未必。
- 純函式管「這個人是誰」，另一份可變狀態管「後來他怎麼了」。
  在 `makeVillagers` 裡多抽一次 `rand()`，整村的名字和年紀都會換一批人。

**驗收**

- Playwright 一定要 `headless: false`（SwiftShader 什麼都畫不出來）且 `page.bringToFront()`
  （macOS 把被遮住的視窗節流到 1 FPS）。
- **每次截圖之前都要再 `bringToFront()` 一遍**，不是開頭喊一次就好：
  `page.screenshot` 是等一幀才回傳的，視窗一被別的窗遮住就卡滿逾時。
  `--disable-backgrounding-occluded-windows` 那幾個 flag 擋不住（那管的是 Chromium
  自己的節流，不是系統層的遮擋）。而且**截圖不要 `.catch(() => {})`** ——
  這批就是這麼五張圖全部無聲失敗，探針卻一路報 ✓。
- 新加一種場所要記得補 `PLACE_VERB` 那張表，漏了牌子上會寫「F · undefined」——
  面板本身好端端的，測試也全綠，只有走到跟前才看得見。
- `__walkToPlace()` 是**用走的**（會真的尋路過去），驗收要瞬移得用 `__placePos()` + `__place()`。
- 探針要驗的東西如果是在**收場那一頁**結的,就得<b>打到收場</b>,不能一看見那一刻就收手。
  義結金蘭那支第一版在「擋刀」觸發的瞬間 break,於是 tally 永遠是 null、
  「記進沒能跟你回來」永遠報 ✗ —— 看起來像接線壞了,其實只是架還沒打完。
- 給 `__battle()` 之類的診斷鉤子加欄位要跟著新機制走。`fx.shielded` 沒露出來的那一版,
  探針只會安靜地說「這一場沒人需要擋」。
- 等 window 把手用 `waitForFunction`，不要等一個猜出來的秒數。
  曾因此量到玩家用 0.25 m/s 走路，查了三輪才發現只是頁面沒載好。
- 「到了沒」要比對**是不是那個地方**。只問「腳下有沒有地方」的話，
  站在市集上就算到了碼頭，後面每一步都在對著錯的面板點按鈕。
- 加一個開場等於一次弄壞所有腳本。所以標題頁只是蓋在世界上面的一層，
  世界一開始就掛著，並且留 `__begin()` 讓腳本跳過。
- 聲音壞掉的樣子就是安靜，和沒做完全一樣 —— 要問音訊圖有沒有建起來，不能靠耳朵。
