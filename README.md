# 白身 · Ancient China NPC Game

一個以**小人物**為中心的漢末開放世界原型。你不是諸侯，是河谷邊某個縣裡的一個白身：
先替人跑腿掙口飯，攢下人情把村裡的人一個一個帶走，再帶著這幾個人去摸山賊的窩。

不是策略遊戲換皮 —— 狀態樹的頂端是**一個人**，不是一個勢力。
你不會有「全國糧倉」這種欄位，你只有「你身上有多少錢、你認識誰、你欠誰人情」。

```
npm install
npm run dev      # http://localhost:5173
npm test         # 戰鬥手感的模擬(vitest)
npm run build
```

WASD 走、Shift 跑、E 搭話、空白鍵揮刀。

## 現在能玩到什麼

- **世界**：程序化河谷 —— 高度場、河、聚落、農田、道路、四季植被、晝夜與天氣。
  一切隨時間變的東西都從單一 `skyFor(hour, season, weather)` 導出，
  各算各的下場是黃昏的太陽配上正午的霧。
- **人**：三十八個有名有姓的村民，各有行當、脾氣、年紀。按時辰出門下田、趕集、歸家，
  路上相遇會停下交談。「有人住」不是靠人多，是靠他們各有各的去處。
- **差事**：活從人嘴裡給，不從選單刷。按行當配活、按身分封頂難度，攤開需要的人手。
  剿匪指的是**地圖上真的那一夥**：接了活它就告訴你往哪走、還有多少步，
  你自己走過去、自己打、再走回來覆命。沒人託你，打贏了也只是私鬥 ——
  錢是你搶的，功勞得有人記。
- **招募**：門檻由脾氣決定 —— 直脾氣講義氣，怕事的得欠你很多。
  有名有姓的伙伴和無名鄉勇分開存：你會記得「王安是第一個跟我走的」，
  不會記得「鄉勇 +1」。
- **打架**：不切場景，架就在你站的這塊地上打。沒有血條，傷勢用姿態講。
  士氣歸零就轉身跑 —— 真實的械鬥多半不是打到全滅。

## 幾條踩出來的規矩

- 顏色烘進 `color` attribute + 材質開 `vertexColors`，一個 InstancedMesh 才能有多種顏色 ——
  這一步讓動畫與批次不再互斥。
- 高度函式必須是純函式，並且網格頂點與物件放置**共用同一份**，
  否則房子會浮空或陷進山裡。
- 障礙要分「擋人」和「擋鏡頭」兩種形狀：樹幹擋人不擋鏡頭，樹冠反過來，
  敞開的堂屋擋鏡頭卻不能擋人（不然村民會被自家卡死）。
- 圓形障礙要走切線。一步只有幾公分，貼上樹幹以後兩個軸都還在圓裡，
  人就永遠黏在那棵樹上；一叢樹圍成的凹角連切線也過不去，所以自動尋路要能往兩邊偏著試。
- 鏡頭求解是三段：**先繞、再抬、最後才收近**。正後方被一棵樹卡住不代表側後方也不行；
  人站在樹冠底下時抬高沒有用 —— 爬過樹梢只會看到一片樹頂，人被葉子蓋住。
- 會走路的東西一律問 `groundAt()` 而不是 `terrainHeight()`，否則橋只是擺著看的：
  主角會從橋底下趟過河，而對岸永遠去不了。畫面上看得見、腳下走不到，比沒有這座橋更糟。
- 戰鬥手感只能空跑一千場調，不能看畫面調 —— 見 `src/game/combat.balance.test.ts`。
- 差事卡上寫「需人 5」，帶了 5 個就得真的打得贏。這個數字是空跑出來的（`menNeeded`），
  而且測試**直接引用同一個函式**：各抄一份，兩邊遲早漂移，
  而漂移的那天畫面上什麼都看不出來 —— 玩家只會覺得這遊戲騙人。
  （早先寫成 `count - 1 + fierce`，毛賊那一段還對，到五個兇賊就成了謊：
  它說帶 6 個，帶 6 個的真實勝率是 16%。兇悍不是加法。）
- 「他是主角」和「他由外面推」是兩件事。合成一個 `isPlayer` 的時候，
  空跑的場子裡主角成了一尊木頭：不動、不揮刀，還照樣吸引兩個賊來砍 ——
  於是量出 4% 勝率，而那個數字量的是**測試少了一個人**，不是遊戲難。
- 擋在鏡頭與主角之間的樹要自己讓開。按「離鏡頭多近」篩兩頭不討好：
  調小了中間那棵照樣糊住你，調大了走在林子裡整片林子跟著融化。
  該問的是**擋不擋著你** —— 判斷改成一根鏡頭指向主角的圓柱，柱子裡的像素才篩掉。
- 鏡頭求解在退無可退時要退到「擋得最少」的那個位置，不是梯級的最後一階；
  最後一階（貼著後腦勺）是所有壞位置裡最壞的一個。
